# Текущий контекст проекта

Дата обновления: 27.10.2026 (Asia/Qyzylorda).

Работа ведётся только в `telecom_catalog_auditor`. `core`, Stage 5, Stage 6, whitelist, production, `.env`, `Dockerfile-local`, модель приложения, зависимости, commit и push не разрешены без отдельного прямого согласования.

Главные источники на старте задачи:

1. `AGENTS.md` — процесс и технические инварианты.
2. `AGREED_REQUIREMENTS.md` — действующие бизнес-правила.
3. `plans/current.md` — единственный указатель на текущий план.

Основной агент активного чата сам планирует, реализует, проверяет итоговый diff и запускает один полный `verify-gate`. Субагенты не создаются без отдельного разрешения Дамира. После каждого этапа агент даёт точные команды и ожидаемый результат для личной проверки; следующий этап начинается только после успешной приёмки и прямого разрешения.

Python читает тестовую MySQL магазина только через VPN и пишет отчёты в локальную SQLite. Новые и проверочные отчёты создаются на отдельной WAL-безопасной копии SQLite. Запись в магазин запрещена.

Исторические документы сохранены в `plans/archive/`. Они не являются текущими инструкциями и не читаются автоматически. Полный прежний handoff: `plans/archive/Handoff_full_2026-10-27.md`.
